## 用户需求

将「基础拖拽组件库组件规划」生成为独立实施计划。当前组件库 `umd_components` 仅有两个组件（CustomHead、CustomList），本次计划按 H5 移动端（375px 画布）拖拽搭建场景，扩充一套完整的组件集，并严格遵循现有组件写法（props.data + argument + description schema + defineExpose + watch）。

## 计划核查结论

本计划为独立任务，与「组件库生成后同步注册到数据库的方案（双格式产物版）」互不影响：

- 注册同步计划保持现状（`ready`），本次不执行
- 本计划只做组件本身的开发与配置面板 schema，不涉及 meta.js、manifest.json 与注册同步链路的改动（属于注册同步计划范围）
- 本计划文件存放于 `umd_components/.codebuddy/plans/`，随项目同步，可在其他电脑查看使用

## 核心功能

- P0 基础必备（7 个）：Text 文本、Image 图片、Button 按钮、Card 卡片、Divider 分割线、Space 空白占位、Banner 轮播横幅
- P1 常用增强（4 个 + 扩展）：Countdown 倒计时、NoticeBar 公告栏、FloatButton 悬浮按钮、Footer 页脚；CustomList 扩展多列网格布局
- P2 表单收集（按需 7 个）：Input、Textarea、Select、Radio、Checkbox、Switch、SubmitBtn
- 落地顺序：P0 → P1 → P2；每个组件均需提供渲染数据默认值、模板渲染、配置面板 schema（使用 `src/config/configuration.js` 的配置类型）

## 技术栈选择

- 沿用现有 Vue 3.5 + Vite 7 单文件组件体系，无新依赖
- `src/config/configuration.js` 提供配置类型：TEXT/NUMBER/CHECKBOX/RADIO/IMAGE/COLOR/BUTTON/RANGE/DATE/TIME/EMAIL/PASSWORD/FILE/TEXTAREA/URL/TEL/SELECT/BOOLEAN/ARRAY
- 构建沿用 `scripts/build.js`（自动按 `src/components/*.vue` 打包为独立产物），本次不改构建脚本

## 组件统一写法（严格遵循 CustomHead.vue / CustomList.vue 范例）

- `defineProps({ data: { ...默认值 } })` 定义渲染数据结构（对象或数组，带默认值）
- `argument`：props.data 的可变 reactive 副本，模板渲染统一用 `argument`
- `description`：配置面板 schema，字段名 → `{ type, label, data? }`；复杂结构（对象、数组）按 CustomHead/CustomList 的嵌套写法
- `defineExpose({ argument, description })` 必须暴露；`watch(() => props.data, ...)` 同步外部数据变化
- 样式用 scoped CSS；图片类默认值复用 `../assets/vite.svg` 占位
- 有定时器/动画的组件（Banner、Countdown、NoticeBar）必须 `onUnmounted` 清理，避免组件卸载后内存泄漏

## 组件设计规格

### P0 基础必备

| 组件 | 渲染数据 data | 配置 schema 要点 |
|---|---|---|
| Text | `{ text, color, fontSize, fontWeight, align, lineHeight }` | TEXT 文本、COLOR 颜色、RANGE 字号、SELECT 字重（正常/加粗）、RADIO 对齐（左/中/右）、RANGE 行高 |
| Image | `{ url, width, radius, mode, jumpUrl }` | IMAGE 图片、RANGE 宽度/圆角、SELECT 裁切模式（等比/填充/裁剪）、URL 跳转 |
| Button | `{ text, link, bgColor, textColor, radius, size, fullWidth }` | TEXT 文案、URL 链接、COLOR 背景/文字、RANGE 圆角、SELECT 尺寸（小/中/大）、BOOLEAN 是否通栏 |
| Card | `{ title, content, bgColor, radius, shadow, jumpUrl }` | TEXT 标题、TEXTAREA 内容、COLOR 背景、RANGE 圆角、BOOLEAN 阴影、URL 整卡跳转 |
| Divider | `{ text, color, thickness, padding }` | TEXT 可选文字、COLOR 颜色、RANGE 粗细/上下间距 |
| Space | `{ height, bgColor }` | RANGE 高度、COLOR 可选背景色 |
| Banner | `{ list: [{url, jumpUrl}], height, interval, autoplay, indicator }` | ARRAY 图片列表（IMAGE+URL）、RANGE 高度/间隔、BOOLEAN 自动播放/指示器；`setInterval` + `onUnmounted` 清理 |

### P1 常用增强

| 组件 | 渲染数据 data | 配置 schema 要点 |
|---|---|---|
| Countdown | `{ endTime, textBefore, textAfter, color, bgColor }` | TEXT/DATE 目标时间、TEXT 前后缀文案、COLOR 颜色；每秒更新剩余时间，`onUnmounted` 清理定时器 |
| NoticeBar | `{ list: [text], bgColor, textColor, speed }` | ARRAY 公告文本、COLOR 背景/文字、RANGE 滚动速度；跑马灯动画 |
| FloatButton | `{ text, icon, link, position, bgColor }` | TEXT 文案、IMAGE 图标、URL 链接、SELECT/RADIO 位置（右下/右下偏上）、COLOR 背景；`position: fixed` 悬浮 |
| Footer | `{ text, link, bgColor, textColor }` | TEXTAREA 内容（版权/联系方式）、URL 跳转、COLOR 背景/文字 |
| CustomList 扩展 | 新增 `columns` | SELECT 列数（1/2 列）；多列时用 CSS grid 布局，保持默认单列外观兼容 |

### P2 表单收集（按需）

| 组件 | 渲染数据 data | 配置 schema 要点 |
|---|---|---|
| Input | `{ label, placeholder, required, defaultValue }` | TEXT 标签/占位/默认值、BOOLEAN 必填 |
| Textarea | `{ label, placeholder, rows, required }` | TEXT 标签/占位、RANGE 行数、BOOLEAN 必填 |
| Select | `{ label, options: [{label, value}], placeholder, required }` | TEXT 标签、ARRAY 选项、TEXT 占位、BOOLEAN 必填 |
| Radio | `{ label, options: [{label, value}], defaultValue }` | TEXT 标签、ARRAY 选项、TEXT 默认选中值 |
| Checkbox | `{ label, options: [{label, value}], defaultValue: [] }` | TEXT 标签、ARRAY 选项、ARRAY 默认选中值 |
| Switch | `{ label, defaultValue }` | TEXT 标签、BOOLEAN 默认开关状态 |
| SubmitBtn | `{ text, link, bgColor }` | TEXT 文案、URL 提交后跳转、COLOR 背景 |

## 落地顺序与验证

1. 第一批（P0）：Text + Image + Button → Card + Divider + Space → Banner
2. 第二批（P1）：Countdown + NoticeBar + FloatButton + Footer → CustomList 网格扩展
3. 第三批（P2，按需）：表单类组件，后续可接入数据收集

每批完成后运行 `pnpm run build:umd` 确认产物正常生成；全部完成后用 [skill:playwright-cli] 在拖拽编辑器中验证：组件面板出现新组件、拖入画布后渲染正确、配置面板 schema 完整可编辑。
